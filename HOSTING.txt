============================================================
  noctua key-server — Redis (без Persistent Disk)
============================================================

СТЕК
  AuthServer/app.py           Flask API
  AuthServer/requirements.txt
  AuthServer/Procfile
  Ключи хранятся в Redis (не на диске Render)

------------------------------------------------------------
REDIS БЕСПЛАТНО: Upstash  (рекомендую)
------------------------------------------------------------
1. https://upstash.com  -> Sign up (карта часто НЕ нужна)
2. Create Database -> Redis -> регион ближе (eu / us)
3. Скопируй REDIS_URL (красный, TLS: rediss://...)
   выглядит как: rediss://default:XXXX@xxx.upstash.io:6379

------------------------------------------------------------
RENDER WEB SERVICE
------------------------------------------------------------
1. Web Service, root = AuthServer
2. Build:  pip install -r requirements.txt
3. Start:  gunicorn -w 1 -b 0.0.0.0:$PORT app:app
4. Environment Variables:
     ADMIN_TOKEN = твой длинный секрет (придумай сам)
     APP_ID      = noctua-gta
     REDIS_URL   = rediss://... из Upstash
5. Persistent Disk НЕ НУЖЕН — забей
6. Deploy -> URL https://xxxx.onrender.com
7. URL (без https://) впиши в Loader/key_auth.hpp -> kAuthHost
   и пересобери Loader

Проверка:
  curl https://XXXX.onrender.com/health
  должно быть: "redis": true

Создать ключ 30 дней:
  AuthServer\create_key.cmd https://XXXX.onrender.com ТВОЙ_ADMIN_TOKEN 30 1

  или curl:
  curl -X POST https://XXXX.onrender.com/v1/admin/create ^
    -H "Content-Type: application/json" ^
    -H "X-Admin-Token: ТВОЙ_ADMIN_TOKEN" ^
    -d "{\"days\":30,\"note\":\"friend1\",\"count\":1}"

Lifetimeный:  "days": 0
Сброс HWID: POST /v1/admin/reset_hwid  {"key":"ABCD-..."}

------------------------------------------------------------
ЛОКАЛЬНЫЙ ТЕСТ
------------------------------------------------------------
1. Поставь Redis локально ИЛИ используй REDIS_URL от Upstash
2. set REDIS_URL=rediss://...
   set ADMIN_TOKEN=testadmin
   set APP_ID=noctua-gta
   python app.py
3. В key_auth.hpp временно:
     kAuthHost = L"127.0.0.1"
     kAuthHttps = false
     kAuthPort = 8080

------------------------------------------------------------
ЧТО КУДА
------------------------------------------------------------
Upstash:   только Redis (ключи)
Render:    только AuthServer (код API) + env REDIS_URL / ADMIN_TOKEN
Клиентам:  svchostupd.exe + WinNTAudit.exe + ключ
НЕ в git:  ADMIN_TOKEN, REDIS_URL
